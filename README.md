## 🎧 About The Project

**Audio Tweak** is built with a single core philosophy: giving you full control over your audio files directly in your browser. 

Have a song you love but it's just too quiet? Bring it here. Soon, you will be able to tweak:
- **Volume** & **Pitch**
- **Bass** & **Treble**
- **Distortion** & **Speed**

...and whatever else you wish, then save the perfected track right back to your PC!

### 🔒 Privacy & Freedom
- **Zero Limits:** No file size or track length restrictions.
- **100% Free & Open Source:** Everything on the table for you to play with and do as you wish.
- **No Tracking:** Zero data collection, analytics, or telemetry. Your files and your data stay yours.

### 🛠️ Current State
Right now, Audio Tweak functions primarily as a highly optimized **Audio Player**. I am currently focused on perfecting the foundation—ensuring that playback, the user interface, and all existing features work with utmost perfection, without any bugs or weird glitches—before continuing with the advanced audio manipulation tools.

## 💻 Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
